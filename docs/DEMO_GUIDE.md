# Demo guide

Use this sequence for a live walkthrough of EduBridge AI.

1. Start the app with the PowerShell commands in `README.md`.
2. Open `http://127.0.0.1:5000/`.
3. Click **Start Learning** and choose a track (Python Programming works well).
4. Set experience level, daily minutes, and target days. Save.
5. Open **Quiz**, answer all questions, and submit when asked to confirm.
6. Review overall score, topic bands, and answer explanations on the analysis page.
7. Open **Study Plan** and generate a plan. Confirm days list weaker topics more often.
8. Mark one or two tasks complete and watch the completion percentage update.
9. Search **Resources** (try `python` or filter by topic).
10. Open **Dashboard** and **Progress** to show charts and statistics from SQLite.
11. Change the display name on **Profile** and reload to show persistence.

If Chart.js fails to load from the CDN, the pages still work and show a short message instead of a chart.

The top banner states that this is a local demo profile without multi-user login.
